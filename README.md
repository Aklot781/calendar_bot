# Telegram-бот для уведомлений о встречах из Google Calendar

## 1. Описание проекта

Данный проект представляет собой Telegram-бота, который подключается к Google Calendar пользователя и:

- отслеживает предстоящие встречи;
- отправляет уведомления в Telegram за заданное время до начала события;
- сохраняет историю последних 10 завершённых встреч;
- поддерживает несколько пользователей;
- корректно работает с часовыми поясами, получаемыми из Google Calendar.

Бот реализован на Python с использованием Google Calendar API и библиотеки aiogram.

## 2. Функциональные возможности

### 2.1 Авторизация

- подключение Google Calendar через OAuth 2.0;
- авторизация выполняется через браузер с использованием `credentials.json`;
- токены доступа сохраняются в базе данных и привязываются к Telegram `user_id`.

### 2.2 Уведомления о встречах

- пользователь задаёт время напоминания (в минутах);
- бот периодически проверяет календарь;
- при наступлении заданного интервала отправляется уведомление.

**Пример уведомления:**

⏰ Напоминание!
Встреча: Обсуждение ТЗ
Время: 09.02.2026 13:20 (UTC+5)
Ссылка: https://www.google.com/calendar/...

### 2.3 История встреч

- сохраняются последние 10 завершённых встреч;
- учитывается время окончания события;
- история изолирована для каждого пользователя.

**Команда:**
`/history`

## 3. Команды бота

| Команда                  | Описание                      |
| ------------------------ | ----------------------------- |
| `/start`                 | Запуск бота и справка         |
| `/connect_calendar`      | Подключение Google Calendar   |
| `/set_reminder <минуты>` | Установка времени напоминания |
| `/history`               | Просмотр истории встреч       |

## 4. Архитектура проекта

**Основные компоненты:**

- `bot.py` — обработка команд Telegram;
- `scheduler.py` — фоновая проверка событий (APScheduler);
- `google_calendar.py` — работа с Google Calendar API;
- `database.py` — хранение пользователей, токенов, истории и уведомлений;
- `logger.py` — логирование;
- `config.py` — конфигурация и переменные окружения.

**Хранение данных**

- используется SQLite (`database.db`);
- все данные привязаны к `user_id` Telegram;
- данные пользователей полностью изолированы.

## 5. Поддержка нескольких пользователей

Каждому пользователю Telegram присваивается уникальный `user_id`.
Для каждого пользователя отдельно хранятся:

- OAuth-токен Google;
- настройки напоминаний;
- история встреч;
- информация об отправленных уведомлениях.

Ограничение авторизации через браузер связано с особенностями OAuth (`run_local_server`).

## 6. Установка и запуск

### 6.1 Требования

- Python 3.13;
- аккаунт Google с включённым Google Calendar API;
- Telegram Bot Token.

### 6.2 Установка зависимостей

pip install -r requirements.txt

### 6.3 Переменные окружения

Создать файл `.env`:

BOT_TOKEN=your_telegram_bot_token
GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_client_secret

## 7. credentials.json

Файл `credentials.json` необходим для OAuth-авторизации Google.

- получается в Google Cloud Console;
- должен находиться в корне проекта.

## 8. Запуск бота

python bot.py

После запуска:

1. Перейти в Telegram
2. Написать `/start`
3. Выполнить `/connect_calendar`
4. Разрешить доступ к Google Calendar

## 10. Безопасность

- токены не хранятся в коде;
- используется `.env`;
- `credentials.json` не публикуется;
- данные пользователей изолированы.
